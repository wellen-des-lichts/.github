# Security Policy

## Supported Projects

This security policy applies to the software projects maintained by Wellen des Lichts, including:

- NoonFinance
- MoscheeMembers

Only actively maintained versions receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report suspected vulnerabilities privately by email:

security@wellen-des-lichts.de

If this address is not yet available, use:

info@wellen-des-lichts.de

Please include:

- The affected project
- A clear description of the vulnerability
- Steps to reproduce the issue
- The possible impact
- Relevant screenshots, logs or technical details

We will review the report and respond as soon as reasonably possible.

## Responsible Disclosure

Please allow sufficient time for investigation and remediation before publicly disclosing a vulnerability.

We appreciate responsible and constructive security reports.

## Scope

Reports should relate directly to software, infrastructure or services maintained by Wellen des Lichts.

Third-party services and systems outside our control are not covered by this policy.
