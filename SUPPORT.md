# Support

Wellen des Lichts provides support for its actively maintained software projects.

## Supported Projects

- NoonFinance
- MoscheeMembers

## Requesting Support

For technical questions, operational issues or general assistance, contact:

info@wellen-des-lichts.de

Please include:

- The affected project
- The version in use
- A clear description of the issue
- Steps already attempted
- Relevant screenshots, logs or error messages

Do not include passwords, access tokens, private keys, personal data or other confidential information.

## Security Issues

Security vulnerabilities must not be reported through ordinary support requests or public GitHub issues.

Please follow the instructions in the organization security policy:

[Security Policy](SECURITY.md)

## Response

Support requests are reviewed according to urgency, project status and the applicable customer agreement.

Wellen des Lichts does not guarantee support for unsupported, modified or outdated versions unless separately agreed.
