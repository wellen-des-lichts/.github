# Contributing

Thank you for your interest in contributing to projects maintained by Wellen des Lichts.

Our goal is to build reliable, maintainable and high-quality software through professional engineering practices.

## Before You Start

Please:

- Read the project documentation.
- Search existing issues before creating a new one.
- Discuss major changes before starting implementation.

## Development Principles

All contributions should follow these principles:

- Clean Architecture
- Readable and maintainable code
- Small and focused commits
- Consistent coding style
- Security by design
- Performance where appropriate

## Pull Requests

Before submitting a pull request, please ensure that:

- The project builds successfully.
- Existing functionality is not broken.
- New code follows the existing architecture.
- Documentation is updated when necessary.

## Commit Messages

Use clear and descriptive commit messages.

Examples:

- feat: add member search
- fix: resolve dashboard loading issue
- docs: update installation guide
- refactor: simplify repository structure

## Reporting Issues

When reporting an issue, please include:

- Project name
- Version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or logs if available
