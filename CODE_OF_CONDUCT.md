# Code of Conduct

## Our Commitment

Wellen des Lichts is committed to maintaining a professional, respectful and inclusive environment for everyone participating in our projects and discussions.

We value:

- Respect
- Professionalism
- Constructive communication
- Technical excellence
- Collaboration

## Expected Behavior

Participants are expected to:

- Be respectful and courteous.
- Provide constructive feedback.
- Focus discussions on technical topics and project improvement.
- Respect different opinions and experiences.
- Help create a positive environment.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination
- Personal attacks
- Offensive language
- Spam or disruptive behavior
- Publishing confidential information without permission

## Enforcement

Project maintainers may remove, edit or reject comments, commits, issues or other contributions that violate this Code of Conduct.
